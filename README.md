# 易经白话

面向第一次阅读《易经》的读者，以用户提供的《周易今注今译》EPUB 为底本，把原文、书中的今注、今译、今释，以及本站导读和自己的理解分层呈现。可以沿着五个问题认识这本书，也可以直接进入原书目录，读一卦、对照注译、写下理解。

当前产品是易经白话解读站，没有课程完成进度、答题评分或每日打卡。旧版学习记录继续保留，集中存档于「阅读档案」。

## 本地启动

项目使用 React 18、Vite 6 和原生 CSS。首次运行：

```sh
npm install
npm run dev
```

打开终端显示的地址，开发环境默认是 `http://127.0.0.1:5173`。端口被占用时，以 Vite 实际输出为准。

生产构建和本地预览：

```sh
npm run build
npm run preview
```

预览默认地址是 `http://127.0.0.1:4178`。请通过开发服务或预览服务打开项目；直接双击 HTML 无法正常加载 React 应用。

`vite.config.js` 已配置 `esbuild.jsx: 'automatic'`，使用 React 自动 JSX 转换，组件无需仅为了 JSX 引入默认 `React` 标识符。

## 底本与来源

当前采用用户提供的《周易今注今译》：王云五主编，南怀瑾、徐芹庭注译，贵州人民出版社，2020 年 8 月第 1 版，ISBN `978-7-221-16026-3`。按书内《周易今注今译凡例》辨认原文、今注、今译和今释，版本信息与凡例均可在原书目录中阅读。

本地导入产物包括 75 个目录条目：六十四卦，以及凡例、序言、《系辞》《说卦》等 11 篇附属内容；共 3431 个文本块与 807 个本地图符、图片资源。保留 EPUB 内源文件、章节锚点与原有图片，不补写纸书页码。`book-index.js` 同时保存来源文件名和 SHA-256 摘要，便于识别所用底本。

## 阅读内容与功能

| 入口 | 可以做什么 |
| --- | --- |
| 五问解读路线 | 从变化、符号、文字层次、白话阅读、生活问题五个角度进入，支持顺读和跳读 |
| 卦象图解 | 点选八卦查看自然意象和爻形；选择或交换上下卦，实时显示全部 64 种组合对应的六爻卦、卦名、卦序和本书卦辞，并进入对应原书章节 |
| 原书阅读 | 按 75 个目录条目阅读，默认查看「原文与今译」，可切换「全部内容」「仅原文」，逐章收藏和写笔记 |
| 白话导读 | 首页保留乾、坤、屯、蒙、需、谦、复、未济八篇入口，对照本书原文、书中解释与本站生活类比 |
| 阅读档案 | 导出或恢复阅读笔记、收藏及已有记录，查看旧版存档，撤销上一次恢复 |

主导航为「解读路线、卦象图解、原书阅读」。首页提供原书凡例入口，帮助辨认书中文字的层次。原书阅读地址使用 `#book/<章节 id>`，例如 `#book/qian`、`#book/fan-li`；全文数据在进入原书阅读后按需加载，目录和版本信息单独保存在轻量索引中。序言、凡例等说明性章节保持完整展示；书内图符支持点击放大。

八篇白话导读提供原文、解释、卦象结构、现代生活类比、思考问题和个人笔记。所引原文按本书校正；书中的注译与本站辅助理解的例子分别标明。生活类比帮助理解文本，不作为原书字面含义或现实事件的预测结论。需要继续阅读完整内容时，可进入对应原书章节。

卦象组合器识别八种上卦与八种下卦构成的全部 64 种组合。选择或交换上下卦后，旁边实时显示对应六爻图、卦名（如「天泽履」）、卦序，以及当前底本的卦辞，并可打开对应原书章节。八篇精选另提供白话导读入口；完整六十四卦的文字与注译在「原书阅读」中查看。

## 保存、迁移与旧数据

阅读位置、逐章笔记与收藏保存在当前浏览器的 `localStorage`，没有账户或服务端同步。主存储键继续使用 `yixue-study-state`；`reader` 包含 `selectedHexagram`、`notes`、`bookmarks`，按章节 id 记录。八篇导读与对应原书卦目共用同一 id，因此笔记和收藏也共用。旧存档缺少这些字段时，会初始化为乾卦和空笔记、空收藏。

笔记与收藏直接在对应阅读页使用，已有内容继续保留并纳入档案备份。旧的 `glossary`、`notes`、`knowledge` 路由回到首页。

旧版案例、每周复盘、课程笔记、草稿和练习历史等字段继续完整保留。旧模块不再出现在主导航，已有记录集中于阅读档案存档，并随完整 JSON 备份一起导出。

浏览器存储按访问来源区分：`localhost` 和 `127.0.0.1`、不同端口、不同浏览器之间不会自动共享记录。因此开发地址和生产预览地址的数据也彼此独立。迁移前请在原地址导出，再到新地址恢复。

备份沿用应用标识 `yixue-study` 和版本 `1`，支持最大 5 MB 的 JSON 文件。导入后先预览导出时间、笔记、收藏及旧版记录数量，点击「用此备份恢复」才会整体替换当前档案。恢复前保存撤销副本；副本或新档案无法写入时，取消恢复并提示原因。撤销会返回恢复前的时间点，恢复后新增的内容应先导出保留。

本地数据损坏或格式不符时，应用暂停自动写入并提供原始数据下载，避免初始化内容覆盖原记录。浏览器空间不足或禁止存储时会显示保存失败提示。清除站点数据或更换设备前，建议先下载一份阅读档案。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/App.jsx` | 页面导航、阅读状态、旧记录存档与本地保存 |
| `src/components/ReaderHome.jsx` | 首页和五问解读路线 |
| `src/components/InterpretationViews.jsx` | 八卦图解、精选卦解读及阅读页内的笔记和收藏 |
| `src/components/BookReader.jsx` | 原书目录、分层正文、来源位置、章节笔记和收藏 |
| `src/data/interpretations.js` | 五问路线、八卦意象、八篇精选解读及来源 |
| `src/data/hexagram-combinations.js` | 依据用户 EPUB 生成的全部 64 种上下卦组合、卦名、卦序、卦辞及原书章节对应关系 |
| `src/data/book-index.js` | 底本版本信息、来源摘要与 75 条目录 |
| `src/data/book.js` | 从用户 EPUB 提取的分层正文与内联图符信息，按需加载 |
| `public/book-assets/` | 从本书导出的 807 个本地图片、图符资源 |
| `scripts/import-book.py` | 根据本书结构重新导入本地 EPUB |
| `src/components/Backup.jsx` | 阅读档案导出、导入预览和撤销恢复 |
| `src/lib/backup.js` | 新旧数据规范化、字段校验与备份格式 |
| `vite.config.js` | 自动 JSX 转换、开发及预览配置 |
| `PROJECT_DESIGN.md` | 产品定位、内容层级和交互设计 |

`divination_learning_guide.md` 保留为项目早期参考材料；当前页面按易经阅读与白话解读的方向组织。

## 重新导入本地书籍

使用 Python 3，在项目根目录执行以下命令，将路径替换为本机 EPUB 文件的位置：

```sh
python scripts/import-book.py "D:\图书\周易今注今译.epub"
```

脚本使用 Python 标准库读取 EPUB 的目录与 XHTML，重新生成 `src/data/book-index.js`、`src/data/book.js` 和 `public/book-assets/` 中的相关资源，不执行书内 HTML 脚本。它按当前底本的文件名、标题与「今注／今译／今释」标记组织内容；更换其他版本前，需要先调整对应的章节规则和版本元数据。
